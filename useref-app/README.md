# 🎯 React useRef Demo – DOM Manipulation & State Handling

This project demonstrates the practical use of **React Hooks** — specifically `useState` and `useRef` — to manage component state and directly manipulate DOM elements.

---

## 🚀 Features

* ✅ Increment counter using `useState`
* ✅ Access and modify DOM elements using `useRef`
* ✅ Change button color dynamically without re-render
* ✅ Simple and beginner-friendly implementation

---

## 🧠 Concepts Covered

### 🔹 useState

* Used to manage state (`count`)
* Triggers re-render when updated

### 🔹 useRef

* Stores reference to DOM element
* Does **not trigger re-render**
* Used for direct DOM manipulation

# React Hook Form – Simple Form Validation

This project demonstrates a basic form built using **React** and **react-hook-form** with simple validation rules.

---

## 🚀 Features

* Form handling using `react-hook-form`
* Input validation:

  * Required fields
  * Maximum length
  * Pattern matching (only alphabets)
  * Number range validation
* Clean and minimal structure

---

## 📂 Form Fields

* First Name (required, max length 10)
* Last Name (required, max length 5)
* Address (required, only alphabets allowed)
* Number (required, between 18 and 50)

---

## 🛠️ Technologies Used

* React
* react-hook-form

---

## ▶️ How to Run

1. Install dependencies:

   ```
   npm install
   ```

2. Start the project:

   ```
   npm start
   ```
